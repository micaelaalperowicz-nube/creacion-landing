# Rental Vial — Landing Page

Landing page de Rental Vial preparada para GitHub y Vercel.

## Incluye

- Catálogo de máquinas organizado por utilidad.
- Galería ampliable de fotografías.
- Botones y acceso flotante a WhatsApp.
- Datos de contacto y redes sociales.
- Meta Pixel `1714475086510162`.
- Evento `PageView` al visitar la página.
- Evento `Contact` al hacer clic en WhatsApp.

## Probar en una computadora

Requiere Node.js 22.

```bash
npm install
npm run dev
```

Luego abrir `http://localhost:3000`.

## Publicar en Vercel

1. Crear un repositorio vacío en GitHub.
2. Subir todo el contenido de esta carpeta a la raíz del repositorio.
3. En Vercel, elegir **Add New > Project** e importar el repositorio.
4. Vercel detectará **Next.js** automáticamente. No modificar los comandos sugeridos.
5. Presionar **Deploy**.

No requiere variables de entorno.
